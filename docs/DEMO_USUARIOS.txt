CONTRASEÑAS (variables .env)
================================================================================
SUPER_ADMIN_EMAIL       → admin@dentista.app (por defecto)
SUPER_ADMIN_PASSWORD    → plataforma + cuenta dual Nova
CLINIC_DEFAULT_PASSWORD → altas clínica, red demo, pacientes seed

Tras `npm run seed:clinics-network` la consola muestra la contraseña aplicada
(por defecto DemoClinic2026! si no defines CLINIC_DEFAULT_PASSWORD).
