# Prompt usado para imagen UI/arquitectura

Crea un mockup UI/UX de altísima fidelidad, estilo SaaS premium, mostrando cómo quedaría una app completa de gestión de citas para dentistas. La imagen debe presentar en una sola composición el FRONTEND para clientes/pacientes y el BACKEND/PANEL ADMIN para la clínica, con diseño moderno, elegante, responsive y totalmente profesional.

Composición: presentación de producto tipo Behance/Dribbble, limpia y detallada. A la izquierda frontend paciente en desktop y mobile responsive; a la derecha backend/admin desktop. Fondo claro con azul dental, blanco, turquesa suave y acentos premium. Bordes redondeados, sombras suaves, iconografía dental elegante, tipografía moderna, app lista para producción.

Frontend: dashboard paciente, reserva, calendario, selección de dentista, tratamiento, precio, historial, recordatorios, notificaciones, reprogramación, perfil, facturas, pagos, mensajes, FAQ y soporte.

Backend: agenda global, pacientes, ficha clínica, odontólogos, gabinetes, disponibilidad, estados de cita, recordatorios, cola de espera, campañas WhatsApp/email/SMS, facturación, pagos, métricas, reseñas, auditoría, roles, configuración, integraciones, reportes y logs.

Añade chips tecnológicos: Astro, React, Supabase, Redis Cache. Añade bloque visual de infraestructura.
